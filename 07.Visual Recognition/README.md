## 1. Machine Learning and Visual Recognition

### 원리
- **기계 학습**을 이용해 이미지 분류, 객체 인식 등 시각적 작업을 수행. 지도 학습과 비지도 학습의 차이 설명.

### 예시
- 고양이, 개, 트럭 등의 이미지를 분류하는 예시를 통해 지도 학습의 원리 설명.

## 2. Image Classification

### 원리
- 주어진 이미지를 고양이, 개 등의 특정 범주로 분류하는 작업. 기계 학습 모델을 사용해 학습함.

### 한계점
- 조명 변화, 물체의 변형, 가려짐 등으로 인해 이미지 분류 성능이 떨어질 수 있음.

### 예시
- 교통 상황에서 차량을 인식하는 작업에서, 다양한 각도와 배경에서도 차량을 인식하는 방법 설명.
