

## 1. Camera Models

### 원리
- **카메라 모델**은 3D 세계 좌표를 2D 이미지로 투영하는 과정에서 사용됨.
- **동차 좌표**는 2D 좌표에 추가 차원을 더해 변환을 쉽게 함.
- **핀홀 카메라 모델**은 작은 구멍을 통해 들어오는 광선을 필름에 투영하는 간단한 원리.
  
### 한계점
- **핀홀 모델**은 조리개가 너무 작아 이미지가 어둡게 찍힐 수 있으며, 렌즈를 추가해야 문제 해결 가능.

### 예시
- 렌즈를 사용하지 않고 찍은 어두운 이미지와, 렌즈를 추가하여 밝기를 개선한 이미지 비교.

## 2. Ordinary and Total Linear Least Squares

### 원리
- **일반 선형 최소 제곱법**은 주어진 데이터를 바탕으로 직선을 찾는 방법. 손실 함수 \((y_i - (ax_i + b))^2\)를 최소화함.
- **전체 선형 최소 제곱법**은 노이즈를 줄이기 위해 고유값 분해를 사용.

### 한계점
- **노이즈**가 많을 경우 이상치에 민감함.

### 예시
- 노이즈가 있는 데이터에서 선형 최소 제곱법이 적합하지 않은 예시와, 이상치를 포함한 데이터에서 전체 선형 최소 제곱법을 사용한 예시.

## 3. RANSAC Algorithm

### 원리
- **RANSAC**은 잡음이 있는 데이터에서 모델을 추정하는 알고리즘으로, 랜덤하게 선택된 데이터로 가설을 세우고 최적의 모델을 찾음.

### 한계점
- 많은 이상치가 있을 경우, 최적의 모델을 찾기 위해 반복적으로 많은 계산이 필요함.

### 예시
- 직선 피팅 문제에서, 이상치가 많은 데이터를 처리하는 과정에서 RANSAC 알고리즘을 사용하는 예시.

## 4. 2D 및 3D 기하학적 변환

### 원리
- **2D 변환**: 이동(Translation), 회전(Rotation), 스케일링(Scaling) 등.
- **3D 변환**: 동차 좌표를 사용해 3D 공간에서 물체의 이동과 회전 등을 설명.

### 한계점
- 투영 변환은 평행선이 교차할 수 있어 왜곡이 발생함.

### 예시
- 카메라가 물체를 회전시키고 이동시키는 과정에서 변환 후에도 기하학적 특성이 어떻게 보존되는지 설명.

## 5. Homography

### 원리
- 두 이미지 간 평면 투영 변환을 설명. 한 이미지의 평면을 다른 이미지의 평면으로 변환.

### 한계점
- 최소 4개의 대응점이 필요하며, 잡음이 많으면 정확도가 떨어질 수 있음.

### 예시
- 두 각도에서 찍은 책의 사진 간의 좌표를 일치시키는 과정을 설명.

---

## 6. Epipolar Geometry

### 원리
- 두 카메라에서 동일한 3D 점을 찍었을 때, 두 이미지 간의 대응점을 찾는 기하학적 원리.

### 한계점
- 두 카메라의 내부 매개변수를 고려하지 않으면, 기본 행렬을 사용한 계산에서 오류가 발생할 수 있음.

### 예시
- 스테레오 비전을 통해 깊이 정보를 얻는 과정 설명.
